# 보고서 위키 편입 검증 — 2026-11-19

합성 PostgreSQL 데이터와 실제 HWPX·PDF 파일로 FastAPI의 보고서 편입 경로를 실행했습니다. **15개 사례가 사전에 정한 기대 결과와 모두 일치**했습니다. 정상 3건은 반영됐고, 중복 2건은 추가하지 않았으며, 오류·미승인·근거 부족 10건은 차단했습니다. 이는 작은 합성 평가의 결과이며 실공장 보고서의 정확도를 추정한 수치는 아닙니다.

## 구현과 경계

`POST /wiki/reports/{report_id}/ingest`는 `{"version":1}`만 받습니다. 서버가 설정된 PostgreSQL 정본에서 보고서·설비·승인·근거를 읽습니다. 코드 검사를 통과한 건만 모델 심사를 받으며, 모델이 `create`, `new_case`, `attach`로 판정하고 응답 검증도 통과한 경우에만 위키와 편입 원장을 새 스냅샷으로 발행합니다. `duplicate`, `hold`, `conflict`, `rejected`와 실행 실패는 현재 발행본을 유지합니다.

코드는 설비 키, 근거 범위·개정·블록 SHA-256·원문 인용, 동일 버전 변경, 개정 계보, 정확한 중복을 검증합니다. LLM은 표현을 달리한 중복, 별도 사건의 유사 사례, 근거와 주장 사이의 모순을 심사합니다. 한 설비의 현재 사례 전체를 비교하며 후보 한도 기본 32건 또는 JSON 입력 64,000자를 넘으면 보류합니다.

보고서는 `Maintenance Case` 페이지로 보존하고 설비·관련 사례에 연결합니다. `synthesize: false`로 과거 사건의 관측·조치를 일반 설비 절차로 재분류하지 않습니다. DB 원본은 조회 전용이며, 위키와 편입 원장은 공유 POSIX 출력 저장소에서 잠금과 원자적 `current` 전환으로 관리합니다.

## 실행 조건

- 모델: 실제 `gpt-5.6-sol`. 동일 모델로 작성·독립 문장 검토·편입 검토를 실행했습니다.
- 연결: 로그인된 Codex CLI의 모델 실행을 로컬 Chat Completions 호환 릴레이로 연결했습니다. 응답 재생이나 모델 대역을 사용하지 않았습니다.
- 실제 모델 호출 26회: 위키 작성 12회, 독립 문장 검토 8회, 보고서 편입 검토 6회. 모두 HTTP 200입니다.
- 원본: 설비 2건, DB 정비 이력 4건 중 현행 2건, 별도 운영 이벤트 근거 2건, 한글 HWPX 매뉴얼 1개, PDF 매뉴얼 1개. 구판 DB 정비 이력은 현행 필터에서 제외했습니다.
- 보고서 정본은 별도의 합성 PostgreSQL DB에 저장했습니다. FastAPI `TestClient`로 실제 라우터를 호출했고 SQL 조회·문서 파싱·모델 호출·파일 발행은 실제 경로를 사용했습니다.
- 이 실행의 한글 파일은 **HWPX**입니다. 바이너리 `.hwp`의 실제 모델 평가를 추가로 실행한 결과는 아닙니다.

## 모델이 잡은 문제와 근거

### 같은 사건을 바꾸어 표현한 보고서

실제 판정: `duplicate`. 보고서는 기존 후보 REP-BASE@1과 동일한 이벤트(EVENT-20261119-C2100), 설비(C-2100), 점검 결과를 표현만 바꾸어 기록했으며, 누설 없음과 토출압력 7.0 bar가 현행 정상 범위 6.5–7.5 bar 이내라는 내용도 동일합니다. 새로운 중요 정보가 없고 같은 매뉴얼 및 이벤트 기록으로 뒷받침되므로 중복입니다.

근거: `src-4fae1dacb63f4b0a611fac33`, `src-84d880c97fe22afe2f8f0d25`. 후보: `REP-BASE@1`.

### 내용은 같지만 별도 사건·근거

실제 판정: `new_case`. 보고서의 EVENT-20261120-C2100은 후보 REP-BASE@1의 EVENT-20261119-C2100과 별개의 점검 이벤트이다. 고정된 현행 매뉴얼 근거는 C-2100/P1 설비의 가동 전 공기 누설 확인 의무와 정상 토출압력 6.5–7.5 bar를 명시하며, 이벤트 기록은 누설 미발견, 가동 전 확인 수행, 토출압력 7.0 bar가 정상 범위 이내였음을 뒷받침한다. 따라서 내용이 유사해도 동일 이벤트의 중복이 아니므로 별도 사례로 등록한다.

근거: `src-4fae1dacb63f4b0a611fac33`, `src-61ea9a69a79e1d509ca22475`. 후보: `REP-BASE@1`.

### 현행 압력 기준 오기

실제 판정: `hold`. 보고서는 현행 정상 토출압력 기준을 5.5–6.5 bar로 기재했으나, 고정된 현행 매뉴얼 R2026.11과 동일 이벤트 기록은 모두 6.5–7.5 bar로 명시한다. 따라서 현재 한계를 중대하게 오기한 보고서이며, 동일 이벤트 후보 REP-BASE@1이 존재하더라도 입고할 수 없다.

근거: `src-4fae1dacb63f4b0a611fac33`, `src-84d880c97fe22afe2f8f0d25`. 후보: `REP-BASE@1`.

### 필수 가동 전 점검을 불필요하다고 기술

실제 판정: `hold`. 보고서의 condition과 action은 가동 전 공기 누설 확인이 필수라는 현행 매뉴얼 R2026.11의 요구사항과 정면으로 모순됩니다. 동일 이벤트 EVENT-20261119-C2100의 기록도 실제로 가동 전에 누설 여부를 확인했다고 명시하므로, 기존 후보 REP-BASE@1과 같은 사건을 다루더라도 이 보고서는 필수 운전 조건을 잘못 진술하여 보류해야 합니다.

근거: `src-4fae1dacb63f4b0a611fac33`, `src-84d880c97fe22afe2f8f0d25`. 후보: `REP-BASE@1`.

### 현재 버전을 명시적으로 대체하는 v2

실제 판정: `attach`. REP-BASE 버전 2는 동일한 report_id와 이벤트(EVENT-20261119-C2100)를 가진 REP-BASE@1을 명시적으로 대체하는 상위 버전이다. 현행 매뉴얼 R2026.11은 가동 전 공기 누설 확인과 정상 토출압력 6.5–7.5 bar를 요구하며, 해당 이벤트 기록은 누설 없음, 점검 수행, 측정값 7.0 bar 및 기록 보완을 모두 뒷받침한다. 따라서 근거가 지원하는 권위 있는 개정 교체본으로서 기존 버전에 attach한다.

근거: `src-4fae1dacb63f4b0a611fac33`, `src-84d880c97fe22afe2f8f0d25`. 후보: `REP-BASE@1`.

검증기는 모든 응답의 후보·원문 ID가 허용된 값인지 확인했습니다. 통과한 3건은 해당 보고서에 고정된 근거만 인용했습니다. 위키 인용의 원문·개정·해시까지 결과 페이지와 원장에 보존합니다.

## 발행·개정 보존 확인

- 미반영 12건마다 `current` 링크와 그 스냅샷의 모든 파일 SHA-256이 실행 전후 같음을 assert했습니다.
- 같은 ID·버전·내용을 재요청하면 `unchanged`였고 모델 호출과 위키 변경이 없었습니다.
- 이미 편입된 같은 ID·버전의 정본 내용을 임의로 바꾸자 `identity_content_conflict`로 차단됐고 현재본이 유지됐습니다. 테스트 후 합성 정본을 복원했습니다.
- 일반 `WikiAgent.run()`도 편입 원장을 유지하고 `unchanged`를 반환했습니다.
- 최종 원장에는 `REP-BASE@1`, `REP-NEW-EVENT@1`, `REP-BASE@2`가 남습니다. 현재 페이지는 `REP-BASE@2`와 별도 사건을 보여주고 이전 스냅샷은 v1을 보존합니다.
- 기준선의 원본 8개 inventory와 원문 근거 해시가 최종본과 같았습니다. 별도 확인한 기존 factory DB 행 및 HWPX·PDF 파일 체크섬도 같았습니다.
- 독립 OKF v0.2 검사기로 4개 스냅샷 모두 통과했습니다. 최종본은 `14 files: 14 ok`입니다.
- 회귀 테스트 **77개 통과**. 모델 대역을 사용하는 이 회귀 테스트와 위의 실제 모델 실행을 구분합니다.

## 검증 중 보완한 점과 남은 범위

처음에는 매뉴얼만 근거로 넣은 보고서를 모델이 보류했습니다. 매뉴얼은 작업 기준을 증명하지만 실제 측정값·점검 결과는 증명하지 못하므로, 합성 DB에 별도 이벤트 근거를 만들고 보고서에 연결했습니다. 필수 근거 검사를 완화하지 않았습니다.

초기 시험에서는 같은 사건의 명시적 새 버전도 표현상 중복으로 분류했습니다. 보고서 ID·상위 버전·명시적 대체 연결이 코드로 확인된 개정은 기존 버전에 `attach`하도록 일반 심사 규칙을 보완하고 최종 15개 사례를 다시 실행했습니다. 잘못된 모델 판정을 코드가 자동으로 통과시키는 변환은 없습니다.

원시 운영 기록과 편입 보고서는 사례 페이지에 보존하고 일반 절차 인용에서 제외하도록 보완했습니다. 최종 실행에서도 C-2100 일반 설비 페이지에는 정확한 정상 압력 범위를 `적용 조건`에 둘지 `가동 전 점검`에 둘지에 관한 문장 검토 조언이 남습니다. 이는 편입 오차단·사실 모순 탐지 실적에 포함하지 않았습니다. 정상 보고서 편입의 오차단은 이번 평가에서 0/3, 오류 미차단은 0/10이지만 전체 위키에 오탐이 없다는 뜻은 아닙니다.

HWPX 위치는 물리 페이지 번호 대신 추출기의 근사 섹션 위치입니다. 더 많은 설비·긴 문서·여러 표현·복잡한 개정 계보는 실제 정답 데이터로 추가 평가해야 합니다. 모델·추출기·프롬프트가 바뀌면 의미 판정 평가를 다시 실행해야 합니다.
